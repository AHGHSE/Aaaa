# Vocab 3600

Interactive vocabulary app for GitHub Pages.

Features:
- Add / Edit / Delete
- Multiple examples, images, audio URL and video URL
- IPA, part of speech, synonyms, antonyms, collocations, word forms
- Search / filter / sort
- Favorites and learning status
- Dashboard / progress
- Quiz
- Spaced review
- Dark / Light mode
- Browser localStorage

## GitHub Pages
Upload the files to a repository, then:
Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Important
GitHub Pages is static. Add/Edit/Delete changes are saved in this browser using localStorage; they are not written back to GitHub. Cross-device sync requires a backend or GitHub API integration.
